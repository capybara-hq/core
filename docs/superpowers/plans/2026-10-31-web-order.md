# Web Order Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the web app one shell, two sidebar contexts and three page frames, with conversation
archive / delete / search, as the web order spec decides.

**Architecture:** Kernel first (conversation archive, soft delete, search, activity), then the design
system (Sidebar v3, PageHeader `path`, one content width, ObjectList / ObjectRow / EmptyState / Callout,
settings frame with groups), then a `check:web-ui` rule that holds the page head, then the pages moved
area by area onto the new frames and routes. Every page keeps its data code; only its frame changes.

**Tech Stack:** NestJS kernel (Kysely, Zod DTOs), Next 16 + next-intl, `@capybara-hq/design` (React, CSS
tokens), vitest + jsdom, Playwright (e2e, visual).

**Spec:** `docs/superpowers/specs/2026-10-31-web-order-design.md` (canvas
https://claude.ai/artifact/UDaSLEyGqqtGP8TXsndoJq). Read §2–§6 before any task.

## Review Focus

1. **Search text with `%`, `_` or `\`**: `?q=50%` must match the literal "50%", not everything →
   Task 2 test `q escapes LIKE wildcards`.
2. **A channel thread whose conversation was deleted**: the next IM message must start a new
   conversation, not post into the hidden one → Task 1 test `delete unbinds channel threads`.
3. **Deleting a conversation that is waiting for approval**: the run ends, the inbox no longer lists
   its approval → Task 1 test `delete stops a waiting run and clears its approvals`.
4. **Old personal-settings links** (`/settings/connections`, bookmarks, the OAuth return URL) keep
   working → Task 9 test `old personal settings paths redirect` and a grep for the OAuth `returnTo`.
5. **Archived conversation opened by URL**: `/chat/<id>` of an archived conversation still opens and
   sending a message to it unarchives it → Task 1 test `a message unarchives`.
