ModeScale

How much power a device gives an agent's commands (spec §6.42, auto mode design §4): one horizontal two-state scale, 自动 | 沙箱, each with one sentence and a 2 px marker under the effective one — never four stacked option cards and never a full-bleed fill. Selection inside the control is neutral (ink), not the accent. A mode the org or the platform forbids is disabled with its reason under it; a cloud device is locked and says why; the whole scale can be off. The command slot holds the local device's KeycapCommand (spec §6.43).
