CheckList

A multi-select of named things with a line of description each (spec §6.39): the checkbox, the name and its badges on the first line (the badges never shrink or wrap), the description as one cut muted line under it; a locked row (a built-in skill) checked and disabled. Grouped, each group's head row is its select-all checkbox with the group's name, mixed while some rows are checked, and the n/m count; a group of locked rows only has its name and count.
