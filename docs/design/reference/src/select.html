Select

The form select (spec §6.2): a field-like button that opens the design system's own list, the composer's anchored menu as a listbox (§6.16.3): below the field, at least its width, the selected option checked; a long list (100 models) capped at layout.menu-max-height with the filter on top, scrolled to the selected one; the placeholder, disabled and error states of the field.
