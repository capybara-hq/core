Project file picker

The composer's 项目文件 (spec §6.16.31): a 640 dialog titled 引用项目文件 that lists one folder of the conversation's device project at a time. The path row starts at the project's name; every segment but the last goes back up. The filter narrows the listed folder's names. Rows: a file's checkbox, a folder icon or a file's type badge, the name, a folder's chevron or a file's size; folders open, files toggle; at the cap the other files are disabled. The count stands at the footer's start, 「引用」 is disabled with nothing chosen. Root: the project root. Folder: src/components, a listing stopped at its cap. Filtered: the root filtered by 「read」. Selected: two files chosen, one in another folder. Empty: an empty folder. Loading: the folder on its way. Unsupported: a device that cannot list files. Compact: the Dialog's bottom sheet, the count over the full-width buttons.
