CopyField

A labelled value people copy and may see again (spec §6.44): a Field's label over a CopyCode (§6.58), whose copy button reads 已复制 for two seconds. Without a usable clipboard the value is selected and a muted line says to copy it by hand. No "shown once" warning (that is SecretReveal).
