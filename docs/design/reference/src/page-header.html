Page header

Row 1: the path (only a page three levels deep or more; a first-level page has none, the sidebar names the place). Row 2: title and a one-line description, actions on the right (at most one solid primary). Below 600 (the narrow block, 390; the compact head, spec §4.2) there is no path row: the large title carries its count in muted mono, the description wraps, the actions go under them (the secondary folded into the head's more menu beside the primary, 44 high), the search takes its own full-width line (filled, no border) above the tabs, which are a segmented control for two or three tabs.
