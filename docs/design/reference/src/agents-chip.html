Agents chip

The agent map's entry (spec §6.16.29, acceptance item AC3): a ghost picker-styled chip in the composer's control row after the effort picker and the quick actions, "N 个智能体", led by the agent map's status dot while a sub-agent runs (accent, pulsing) or waits for a person (warn); no dot when nothing is active. It replaces the title bar's agent map icon. Below 640 (the narrow block, drawn in a 390 window) it is the dot, or the agent icon when nothing is active, and the count; the full text stays its name and tooltip.
