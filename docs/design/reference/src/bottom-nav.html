BottomNav

The compact class's navigation (spec §4.6, §6.45; mobile layout spec §4.2): four items in the fixed order 会话 · 智能体 · 收件箱 · 我, each `layout.bottom-nav` (56) high and a quarter of the width, on the sidebar ground with a `line-soft` top line, an icon 16 over a `micro` label. The current item takes the `sidebar-active` ground, `ink` and weight 600. The inbox item carries the pending count as a badge. In a short window (below 480 high; drawn at the iPhone Duo outer display, 382) the labels go and the names stay. The home-indicator inset and the keyboard (which hides the bar) are not drawn.
