MePanel

The Me tab's page body (spec §6.48; mobile layout spec §4.2), drawn by the shell from the sidebar's data: the account row and the org switcher (a bottom sheet), the 工作区 group (技能, 连接器, 定时任务, 设备; guests only 连接器 and 设备), the 管理 group (插件, 扩展, 渠道, 评测与运行, 组织设置 for org admins and owners; 管理后台 last for super admins; no group when the role has no row), the account group and the system status line. In the admin context the same panel lists the console's pages in 管理, 回到工作区 last, with no 工作区 group. Rows are `row.roomy` high, split by `line-soft`, in no box.
