Composer menu

The composer's ＋, / and @ menus share one shell (spec §6.16.30): as wide as the composer, attached space.2 above it, the menu ground and line, the list capped by layout.menu-max-height. Rows carry an icon for their kind (a command's terminal, a skill's sparkles), a connector's mark for its rows, prompts and resources, a file's type for files; names never start with / or $; the active row is on selected. No search box of its own: the query is the composer text after the trigger. The footer's key hints (from 841 up): @ and / switch menus. Plus: 添加, 能力 and one row per connector (one waiting for setup, 待配置, disabled). Slash: skills by source, a connector's prompts, the command last. At: the files matching 「季度」, then resources by connector. Conversations: the files, then the 会话 group (the chats icon, the title, 「 · 」). Empty: nothing matches. Loading: results on their way. Compact: the / menu as a bottom sheet with a search field on top, rows touch.row high, no key hints.
