# Skills

Skills are compatible with the Anthropic Agent Skills format: a directory with a `SKILL.md` at its root that has `name` / `description` frontmatter, and it can carry scripts and other files. Metadata is in PG and files are in object storage (so install an object-store extension first).

- **Skill library** ("Skills" in the top bar): an org admin uploads a zip (≤ 50MB, each file ≤ 10MB, total after unzipping ≤ 50MB; `SKILL.md` sits at the root or in the single top-level folder), and uploading the same name again creates a new version; members can browse. When editing an agent, tick the org skills to use in the "Skills" group.
- **At runtime**: when a conversation starts a run, the kernel writes the list of skills available to that agent (name + description) into the conversation log and tells the model; the model reads the body by name with the builtin tool `Skill`. Skills that carry scripts are copied into the environment's `/skills/<name>@<digest>/` (one directory per skill version; read-only, run with `sh` / `python3`), and the agent needs sandbox tools. When skills change, the model gets a reminder at the **start of the next run**.
- **Agents writing their own skills**: add the builtin tool `SkillWrite` to an agent (not included by default). Skills written by a private agent take effect immediately; when a shared agent writes a skill, the initiator first confirms that tool call in the conversation, and then it goes to the agent owner's "Inbox" for approval; until approved, only the conversation that initiated the change can try it, and once approved all conversations use the new version from their next run. The owner can delete an agent's self-written skills on the agent edit page.
