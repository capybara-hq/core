New package `@capybara-hq/device`: the `capybara-device` program with `login`, `logout`, `status`, `start`, `stop` and `drain`: the connection to the deployment, operation dispatch, results kept across reconnects and a local command log. The plugin-tools dependency check can hold a package to the plugin-sdk-only boundary (`deviceDirs`).
