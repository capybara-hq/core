The org extensions settings page lists the file previewers (`file-preview@1`) of enabled extensions, in the order the org tries them, with up / down and an enable switch. Embed previewers receive the file over the message bridge after `init`.

The conversation page is rebuilt on the `ConversationPage` template: a title bar with the generated title and rename, tool calls grouped after Claude Code (titles, key arguments, shell descriptions, diffs, failures from exit codes, "View all" for archived output), thinking rows, run dividers (stopped, failed with Retry, compacted with the saved tokens, model fallback, extension policy), the approval, question and connect blocks, file outputs, and a composer that holds the agent, model and effort pickers. ↵ sends (interjects while a run is going), ⌘↵ / Ctrl+↵ queues (with the pending model and effort pick); queued messages show under the thread with copy, edit, delete, "Send now" and "Continue sending" after a pause. "New conversation", the Agents list and a sidebar group's ＋ open `/chat` (`?agent=`), and the conversation is created on the first send. The sidebar reloads when a title changes. `PlaygroundPage` is removed.

The conversation's right area holds one thing at a time, kept in the URL hash (`#properties`, `#panel=<plugin>/<contribution>[/<item>]`, `#file=<id>`, `#output=<callId>`, `#subagent=<id>`): the properties panel (Context, the extensions' sections, Files including the sub-agents' deliveries marked with the sub-agent, then Background tasks), an extension's right panel (a rendered view scrolled to an open target's item, or an embed), a file preview (extension previewers first, then the built-in image, text, Markdown and CSV / TSV previewers, else the file card with Download) a call's full archived output, or a sub-agent's record (Back returns to the properties panel when it was opened from there; an org agent's name links to the agent). Extension inline cards hang off their tool calls. Each extension block loads on its own (10 s) and fails alone with "Failed to load · Retry". The Run, Context and Artifacts tabs are gone.
