企业目录网页：后台「企业目录」（列表按种类与来源筛选、显示来源与「有新版本」，导入文件或 npm 包）、条目详情（策略切换、插件条目装到部署、删除、版本）、导入应用的一次审阅（各插件权限分组与敏感项、安装 / 升级 / 保持，连接器模板与技能；可选同时装到部署，并说明不装时组织用不了；有敏感项须勾选「我已了解敏感项」）、浏览清单（不兼容的版本置灰，引入时 integrity / lock 不符醒目报错，权限摘要不一致警告，条目截断时提示）、目录来源（官方清单开关与只读地址、离线模式、企业清单增删改、状态与立即刷新）、部署申请。组织侧一级导航「目录」（按 installable 显示安装 / 申请）、条目详情、连接器模板与应用的安装向导（只能改可编辑的端点字段，失败时说明失败的步骤与已回滚；`/connectors/install?template=` 走同一向导）、设置里的「已安装的应用」（卸载后按报告列出移除与保留项及原因，安装中给出友好说明）、收件箱里的目录申请卡片；组织插件启用被目录条目拒绝时给出原因与去目录的入口。条目图标只经内核路由以 `<img>` 显示。
