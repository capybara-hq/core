- MCP elicitation、prompts：内核提供 `onElicit` 时声明 elicitation 能力（表单 + URL 两种模式），把服务发起的 `elicitation/create` 交给 `onElicit` 并原样回复答复；工具调用返回 `-32042`（URL elicitation required）时逐个交给 `onElicit`，全部接受后重试一次调用（没有 `onElicit` 或用户未完成 → 英文 ToolError 说明需要的浏览器步骤）。服务声明 prompts 能力时会话带 `listPrompts` / `getPrompt`（内容块按工具结果的规则映射）。
- 新增 MCP 连接器插件 `@capybara-hq/plugin-connector-mcp`（`connector@1`，kind `mcp`，官方 `@modelcontextprotocol/sdk` 的 Streamable HTTP 客户端）：端点 `{ url, headers }`（url 须为 https；部署配置 `allowInsecureLoopback`（默认 false）打开时才允许确切的 `127.0.0.1` / `localhost` / `[::1]` 用 http；不跟随重定向，3xx 一律报错；headers 为非密钥固定头，不允许 `Authorization` / `Cookie` 等凭据头）；每个 HTTP 请求前调用内核的 `auth()` 合并鉴权头 / query，401 → `onUnauthorized()` 后重试一次，仍失败抛 `ToolError("Authentication failed for this app; ask the user to reconnect it.")`；工具清单映射 `name / description（缺失用 title 或 name 并 warn）/ inputSchema / annotations`（`_meta["anthropic/requiresUserInteraction"]` → `requiresUserInteraction`），调用结果映射 text / image / resource_link，嵌入资源转文本，音频与二进制资源给出类型说明；服务端 JSON-RPC 错误 → `ToolError` 带服务说明，HTTP 非 2xx → `ToolError` 只带状态码、正文（截断）记 warn 日志；服务声明 resources 能力时会话带 `listResources` / `readResource`。会话在单次操作内打开并关闭，不缓存连接。
  错误带 `ToolError.kind`：HTTP 5xx 与连不上服务（`Could not reach the app's server. Retry later, or ask an administrator to check the app.`）为 `unavailable`（计入内核的应用熔断），JSON-RPC 业务错误、其他 4xx、401 重试后仍失败、重定向为 `error`（不计入）。
- 工具定义漂移检测与复核（spec 7.3）：维护队列每 `tools.driftIntervalHours` 小时（job scheduler `drift-scan-interval`，多副本只有一个）对活动应用重新 listTools，与快照比对——新增工具 `pending_review`；定义变化 → `pending_review`（新定义存 `pending_spec`，旧定义保留供对比）；消失 → 停用并标记 `missing`。`POST /api/v1/orgs/:orgId/apps/:appId/refresh` 改走同一套比对；新增 `POST .../apps/:appId/tools/:name/review {action: "approve" | "reject"}`（`apps.manage`，错误码 `app.tool_not_found` / `app.tool_not_pending`），approve 采用新定义并启用、默认策略按新注解重新推导（管理员设定的策略保留，工具视图新增 `policySource` / `pending` / `missing` / `reviewedAt`），reject 停用并保留旧定义；待复核的工具不能经 PATCH 启用。审计 `app.tools_drifted`（只有计数）与 `app.tool_reviewed`。个人凭据型应用的后台检查依次试至多 3 个现任成员的个人凭据。迁移 `0015_tool_drift.sql`。
  SDK：`ConnectorOpenArgs` 新增可选 `onToolsChanged?: () => void`（会话中远端报告工具清单变了时调用，内核投递一次漂移检查，jobId `drift-<appId>-<分钟桶>`）。connector-mcp：收到 `notifications/tools/list_changed` 时调用它。测试工具：`startFakeMcpServer` 新增 `sseResponses`，工具处理函数第二个参数 `ctx.notifyToolsChanged()`。
