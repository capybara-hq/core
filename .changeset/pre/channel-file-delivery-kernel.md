Conversation files (`Deliver`, `GenerateImage`, every `artifact_created`) reach the IM chat or thread through the optional `channel@1` `sendFile`, images as images; a file that cannot be sent becomes one line linking to the web conversation. New config `channels.fileMaxBytes` (default 20 MiB, 0 = links only) and `channels.fileConcurrency` (default 4).
